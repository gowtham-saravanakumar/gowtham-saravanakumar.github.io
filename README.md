# Gowtham Saravanakumar — Portfolio

Premium light-first personal portfolio for Gowtham Saravanakumar, SEO Specialist & Digital Growth Strategist.

## Experience

- Editorial, whitespace-led light theme with a carefully tuned dark mode
- CSS 3D hero and depth system (no heavy WebGL dependency)
- Pointer-reactive depth, project tilt and magnetic interactions on capable desktop devices
- Scroll parallax, timeline activation and progressive content reveals
- `prefers-reduced-motion` support and simplified mobile interactions
- Responsive navigation, semantic sections, keyboard focus states and labelled forms
- Selected work, services, skills, tools, testimonials, writing and project enquiry flow
- Theme preference saved with `localStorage`
- Search metadata, Person schema, sitemap and robots.txt

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

This repository is static and can be published directly with GitHub Pages. Commit the files to the repository used by `gowtham-saravanakumar.github.io` and deploy from the repository root.

## Key files

- `index.html` — portfolio content and semantic structure
- `assets/css/portfolio.css` — responsive design, themes, 3D and motion styling
- `assets/js/portfolio.js` — interactions, parallax, theme, navigation, testimonials and form handling

The existing blog pages and image assets are preserved.
